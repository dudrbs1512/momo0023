# 후기 게시판 연결 방법 (Supabase 무료 플랜)

약 10분 걸립니다. 한 번만 하면 됩니다.

## 1. 프로젝트 만들기
1. https://supabase.com 에 가입하고 로그인합니다.
2. **New project**를 누릅니다.
   - Name: `momo` (자유)
   - Database Password: 아무 값이나 길게 정한 뒤 따로 보관합니다.
   - Region: **Northeast Asia (Seoul)**
3. 생성이 끝날 때까지 1~2분 기다립니다.

## 2. 게시판 테이블 만들기
1. 왼쪽 메뉴에서 **SQL Editor**를 엽니다.
2. 이 폴더의 `schema.sql` 내용을 전부 복사해서 붙여넣습니다.
3. **Run**을 누르고 `Success`가 뜨는지 확인합니다.

## 3. 홈페이지에 연결하기
1. 왼쪽 아래 **Project Settings**에서 **API**(또는 **API Keys**)로 들어갑니다.
2. 아래 두 값을 복사합니다.
   - **Project URL**: `https://xxxx.supabase.co` 형태
   - **anon public** 키 또는 **Publishable** 키 (`eyJ...` 또는 `sb_publishable_...`로 시작)
   - ⚠️ `service_role` / `secret` 키는 **절대** 홈페이지에 넣지 마세요.
3. `index.html` 맨 아래쪽에서 다음 두 줄을 찾아 값을 넣습니다.
   ```js
   var SUPABASE_URL = '';   // ← Project URL
   var SUPABASE_KEY = '';   // ← anon / publishable 키
   ```
4. 저장하고 홈페이지를 새로고침하면 바로 이야기를 등록할 수 있습니다.

## 4. 운영·관리
- **글 숨기기**: Supabase의 **Table Editor**에서 `stories`를 열고, 해당 글의 `is_hidden`을 `true`로 바꿉니다.
- **글 완전 삭제**: 같은 화면에서 행을 선택한 뒤 Delete를 누릅니다.
- **고객이 비밀번호를 잊었을 때**: 비밀번호는 암호화되어 있어 확인할 수 없습니다. 본인 확인 후 관리자가 직접 숨기거나 삭제해 주세요.

## 참고
- 무료 플랜 프로젝트는 **7일 동안 접속이 없으면 일시정지**될 수 있습니다. 대시보드에서 다시 켜면 되고, 데이터는 남아 있습니다. 홈페이지 방문이 꾸준하면 거의 문제되지 않습니다.
- 비밀번호를 5번 틀리면 그 글은 15분 동안 수정·삭제가 잠깁니다.
- 1분에 10건이 넘게 등록되면 도배 방지를 위해 잠시 등록이 막힙니다.
